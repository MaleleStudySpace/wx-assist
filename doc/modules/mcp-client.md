# MCP 扩展

## 1. 功能定位

MCP Client 让用户把外部工具服务接入摘星。外部服务可以是本地子进程，也可以是远程 HTTP 服务；连接成功后，工具会加入 Agent 的工具列表。

项目同时提供反向 MCP Server：外部客户端可以读取摘星提供的查询工具。两者方向不同，互不替代。

## 2. 工作流程

```text
用户配置外部 MCP 服务
  → 启动并完成协议握手
  → 获取工具列表
  → 以 server__tool 命名注入 Agent
  → Agent 选择工具
  → MCP Client 发起调用
  → 结果回填 Agent 对话
```

## 3. 配置要点

支持：

- `stdio`：启动本地命令；
- `http`：连接远程 MCP 端点。

配置包含名称、传输方式、命令或 URL、参数、超时、启用状态和可选描述。凭据应使用用户自己的安全配置，不要写入公开文档或提交仓库。

## 4. 可用性

- 启动时逐个连接，单个服务失败不影响其他服务；
- 后台定期健康检查；
- 连续失败时暂时移除工具，恢复后重新加入；
- 可在 MCP 管理页面新增、删除、重启、启停服务和工具。

## 5. 安全边界

- 外部工具只在用户明确配置后加载；
- 工具名称使用服务名前缀，避免同名覆盖；
- 外部服务不能继承应用的敏感运行环境；
- 反向 MCP Server 的写操作会被限制，因为外部调用无法完成交互确认。
