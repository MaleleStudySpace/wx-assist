# 上手指南

## 1. 首次启动

1. 启动桌面应用或本地 Web 服务；
2. 按页面向导完成本地数据目录和账号配置；
3. AI 服务可以跳过，之后在系统配置中补充；
4. 选择需要启用的提醒、摘要和推送渠道；
5. 点击“启动”后，Dashboard 会显示运行状态。

应用会分别显示“网页服务”和“助手服务”的状态。网页可以打开但助手尚未启动，这属于正常的启动阶段。

## 2. 建议配置顺序

```text
基础运行配置
  → 消息推送渠道
  → AI Provider（可选）
  → 关键词提醒
  → 群聊/公众号摘要
  → 通用定时任务与 Skill
```

如果只需要浏览和导出本地内容，可以不配置 AI 和推送渠道。

## 3. 最小使用路径

### 浏览消息

打开“会话管理”，选择会话即可查看、筛选和导出消息。媒体显示失败时，不影响文本消息和导出任务。

### 使用关键词提醒

在“群聊助手”中创建提醒组，选择会话和关键词，保存后等待新消息命中。提醒会进入通知中心；绑定渠道后也会自动投递。

### 使用摘要

创建摘要分组，选择一个或多个会话、时间和风格。摘要生成需要 AI；没有新消息时会记录执行结果但不发送空摘要。

### 使用公众号助手

公众号文章列表、搜索和缓存不要求 AI。定时摘要需要 AI；即时提醒可以在 AI 不可用时使用文章已有摘要或标题作为降级内容。

### 使用 Agent

绑定消息渠道并配置 AI 后，可以通过私聊或本地测试接口请求 Agent。修改配置、创建任务等操作会先要求确认。

## 4. 未配置 AI 时

未配置 AI 不会阻止项目启动。以下功能仍可用：

- 消息、收藏、朋友圈浏览；
- 本地搜索和导出；
- 关键词提醒；
- 公众号文章读取和即时提醒；
- script 类型 Skill；
- 通知渠道本身。

以下功能需要补充 AI：

- 群聊/公众号定时摘要；
- AI 对话和朋友圈 AI 总结；
- Agent；
- prompt 类型 Skill；
- AI 记忆整理。

## 5. 停止和重启

修改基础配置、AI Provider 或数据目录后，建议停止并重新启动助手。提醒、摘要和公众号分组配置通常可以通过页面热更新。

## 6. 公开文档中的示例

公开文档不包含真实账号、联系人、会话、凭据、个人目录或运行数据。部署时请使用自己的配置，并避免将配置文件和运行数据提交到仓库。
